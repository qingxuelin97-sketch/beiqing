# 中共历次代表大会与中央全会资料库 · 产品需求文档（PRD）

## 1. 产品概述

本项目旨在构建一个权威、严谨、富有视觉冲击力的党史资料检索与展示网站，系统收录中国共产党第一次全国代表大会至第二十届中央委员会第四次全体会议期间的所有全国代表大会与中央委员会全体会议资料。
- **核心目标**：以官方公开资料为准绳（人民日报、新华社、人民出版社《中国共产党历次代表大会及重要全会资料》、中央党史和文献研究院编《中国共产党历届中央委员大辞典》《中国共产党历史》等），为研究者、党员、学生与公众提供准确、可追溯的党史学习平台。
- **价值定位**：在宪法与党章框架下传播党史知识，弘扬红色文化，所有内容均标注官方出处，杜绝臆造与不实信息。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通访客 | 无需注册 | 浏览全部公开资料、检索、收藏（本地）、查看时间轴 |
| 研究者 | 无需注册 | 同上，可导出引用格式（GB/T 7714） |

### 2.2 功能模块
1. **首页**：红色主题 Hero、党徽党旗动效、历次代表大会时间轴入口、关键数据统计、最新收录
2. **代表大会列表页**：一大至二十大卡片网格，按届次筛选与排序
3. **中央全会列表页**：按届次浏览历次中央委员会全体会议
4. **会议详情页**：基本信息、主要议程、通过文件、人事变动、历史意义、官方出处
5. **时间轴页**：1921 至今的可视化时间轴，支持横向滚动与缩放
6. **检索页**：全文检索 + 多维筛选（届次、年份、会议类型、关键词）
7. **关于页**：资料来源说明、版权声明、宪法与党章遵循声明

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | Hero 区 | 党徽粒子动效、主标题渐入、滚动指引 |
| 首页 | 数据看板 | 历届代表大会数、中央全会数、收录文件数 |
| 首页 | 时间轴入口 | 横向滚动卡片，点击跳转详情 |
| 代表大会列表 | 筛选栏 | 按届次/年代筛选 |
| 代表大会列表 | 卡片网格 | 每张卡片含届次、年份、地点、主要议题 |
| 中央全会列表 | 届次导航 | 一至二十届横向 Tab |
| 中央全会列表 | 全会列表 | 该届历次全会卡片 |
| 会议详情 | 信息卡 | 时间、地点、出席人数、主要议程 |
| 会议详情 | 文件清单 | 通过的报告、决议、章程修正案 |
| 会议详情 | 人事变动 | 中央委员、政治局、常委变动 |
| 会议详情 | 出处标注 | 每条信息标注官方来源 |
| 时间轴 | 主轴 | 横向时间线，节点为历次会议 |

| 关于 | 声明 | 资料来源、宪法遵循、版权 |

## 3. 核心流程

用户访问首页 → 浏览时间轴/数据看板 → 点击进入代表大会或中央全会列表 → 选择具体会议查看详情 → 在详情页查看议程、文件、人事、出处 → 可通过检索页快速定位。

## 4. 用户界面设计

### 4.1 设计风格
- **主色**：中国共产党党旗红 `#C8102E`（中国红），辅以深红 `#8B0000`、暗红 `#5C0000`
- **辅色**：党徽金黄 `#FFD700`、米金 `#E8C26A`、宣纸米白 `#F5EFE0`
- **背景**：深红渐变 + 暗金纹理，营造庄重肃穆的党史殿堂氛围
- **字体**：标题使用「方正小标宋简体」风格衬线字体（思源宋体 Source Han Serif），正文使用「思源黑体 Source Han Sans」，数字使用衬线体增强历史感
- **按钮**：金色描边 + 红色填充，hover 时金色光晕扩散
- **布局**：以纵向叙事为主，时间轴采用横向滚动，详情页采用左右分栏
- **图标**：使用 lucide-react 线性图标，搭配党徽五角星元素
- **装饰元素**：党徽图案水印、长城纹饰边框、传统回纹分隔线

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页 | Hero 区 | 深红渐变背景、党徽粒子、金色标题、滚动指引动画 |
| 首页 | 数据看板 | 金色数字 + 衬线字体、计数动画 |
| 首页 | 时间轴预览 | 横向滚动卡片、3D 倾斜效果 |
| 代表大会列表 | 卡片网格 | 红金配色卡片、hover 抬升 + 金边发光 |
| 中央全会列表 | 届次 Tab | 金色下划线指示器、滑动切换 |
| 会议详情 | 信息卡 | 米白底 + 红色标题 + 金色分隔线 |
| 会议详情 | 出处标注 | 灰色小字 + 引号图标 |
| 时间轴 | 主轴 | 金色时间线 + 红色节点 + hover 弹出卡片 |
| 检索 | 搜索框 | 红色边框 + 金色聚焦光晕 |

### 4.3 响应式
- 桌面优先（≥1280px）：完整三栏/双栏布局
- 平板（768-1279px）：双栏自适应
- 移动端（<768px）：单栏纵向、时间轴改为纵向、触摸优化（增大点击区域、滑动切换）

### 4.4 动效与体感反馈
- **页面进入**：标题逐字渐入 + 金色光带扫过
- **滚动揭示**：IntersectionObserver 触发卡片错峰上浮 + 淡入
- **悬停反馈**：卡片 3D 倾斜（perspective + rotateX/Y）、金边发光、阴影加深
- **点击反馈**：按钮按下缩放 0.96 + 涟漪扩散
- **时间轴**：节点脉冲呼吸、连线流光动画
- **页面切换**：React Router 过渡 + 红色幕布滑入/滑出
- **微交互**：数字滚动计数、文字打字机、粒子背景缓慢漂浮

## 5. 内容来源与合规声明

### 5.1 资料来源（均为官方公开出版物）
1. 中央党史和文献研究院编《中国共产党历史》（第一卷、第二卷、第三卷）
2. 人民出版社《中国共产党历次代表大会及重要全会资料》
3. 《中国共产党历届中央委员大辞典》
4. 人民日报、新华社历次党代会/全会报道
5. 《中国共产党章程》历次修订版本
6. 《关于建国以来党的若干历史问题的决议》
7. 《中共中央关于党的百年奋斗重大成就和历史经验的决议》
8. 党的领导人官方传记（中央文献研究室编）

### 5.2 合规原则
- 所有内容严格遵循《中华人民共和国宪法》与《中国共产党章程》
- 坚持历史唯物主义，客观呈现历史进程
- 不传播任何损害国家利益、社会公共利益的信息
- 涉及历史评价以党中央正式决议为准
- 所有数据均标注可追溯的官方出处

## 6. 非功能需求
- **性能**：首屏 LCP < 2.5s，路由切换 < 300ms
- **可访问性**：语义化 HTML、键盘导航、ARIA 标签
- **SEO**：静态元数据、结构化数据
- **浏览器兼容**：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
